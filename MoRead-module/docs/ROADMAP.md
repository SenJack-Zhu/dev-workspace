## 各需求详细说明

### ✅ 已完成

#### 模块系统基础框架
- **描述**：基于 Rhino JS 引擎的模块运行环境，HookRegistry 钩子注册/分发系统
- **关键文件**：`HookRegistry.kt`, `ModuleLoader.kt`, `JsEngine.kt`
- **完成时间**：早期

#### 文本精校模块
- **描述**：标点规范化、错别字替换、空白清理、自定义替换（支持正则）
- **钩子**：`text.display`, `text.preprocess`
- **状态**：v1.1.0，内置模块
- **文件**：`modules/text-proofread.mrm`

#### TTS 增强模块
- **描述**：自定义 TTS 端点、自定义音色列表、自定义断句
- **钩子**：`tts.synthesize`, `tts.voices`, `listen.sentence`
- **状态**：v1.0.0，内置模块
- **文件**：`modules/tts-enhance.mrm`

---

### ⏳ 进行中

#### 智能文本理解模块 (smart-text)
- **描述**：AI 辅助的自增长知识库，智能区分对话与专有名词
- **核心特性**：
  - ✅ 三层知识库（本书 → 全局 → 启发式）
  - ✅ 三态模型（已确认 / 学习中 / 已拒绝）
  - ✅ 启发式规则引擎（姓氏、后缀、长度、上下文动词）
  - ✅ AI 逐章学习模式
  - ✅ 待审核列表（双轨学习）
  - ❌ 全书预扫模式
  - ❌ 知识库导入导出 / 题材包分享
  - ❌ UI 管理界面（搜索/编辑/批量确认）
- **钩子**：`dialogue.segment`
- **状态**：v0.2.0，非内置
- **文件**：`modules/smart-text.mrm`

#### 提示词管理器 (prompt-manager)
- **描述**：集中管理所有 AI 功能的提示词，支持自定义覆盖
- **核心特性**：
  - ✅ 有声书剧本 prompt 自定义
  - ✅ 随读段评 prompt 自定义
  - ✅ 独立开关（关了就用默认）
  - ✅ 变量替换
  - ✅ 酒馆角色卡 JSON 解析
  - ❌ 角色卡自动映射到各功能 prompt
  - ❌ 更多功能 prompt 覆盖（封面/记忆/回复建议）
  - ❌ 提示词模板包导入导出
- **钩子**：`prompt.audiobook.script.system`, `prompt.annotation.proactive.system`
- **状态**：v0.1.0，非内置
- **文件**：`modules/prompt-manager.mrm`

## 版本迭代策略

每次作者升级 MoRead 版本后，按以下步骤重新应用模块系统：

1. **检查钩子清单** — 对照 `HOOKS.md` 逐个确认钩子位置和签名
2. **修复失效钩子** — 如果函数签名变了，更新钩子调用
3. **新增原生钩子记录** — 如果作者加了新钩子，更新 HOOKS.md
4. **验证模块** — 测试每个模块是否正常工作
5. **更新文档** — 同步更新 HOOKS.md / ROADMAP.md / README.md
