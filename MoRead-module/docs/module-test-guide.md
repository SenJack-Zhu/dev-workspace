# 模块测试文本

这篇测试文本专门用于测试 MoRead 模块引擎的三个内置模块：**文本精校**、**TTS 增强**、**智能文本**。
文本约 1000 字，包含各种常见错误和典型场景。

---

## 测试文本

夜色下的临江城灯火澜珊，张伟站在窗前，手里拿着一份刚到的文件。

"你明天真的要去吗？"李晓雅从背后抱住他，声音有些发颤，"听说那边的情况很复杂，我担心你。"

张伟转过身，轻轻模了摸她的头："放心吧，只是去做个调查，很快就回来。上次那么危险的情况我们都挺过来了，这次应该没问题的。"

李晓雅抬起头，眼里闪着泪光："可是...可是我听说这次的对手跟以前不一样。他们说，那个人很危险。"

"那个人？"张伟的眉头皱了起来，"你是说...陈浩然？"

李晓雅点点头，咬了咬嘴唇："我也是听我爸说的。他说陈浩然三年前就回来了，一直在暗中发展势力。这次的事情，很可能跟他有关。"

张伟沉默了。三年前的那件事，是他心里永远的痛。他最好的兄弟，就是在那件事里牺牲的。

"不管是谁，"张伟的声音变得坚定，"我都必须去。有些事，总得有人去做。"

第二天一早，张伟就出发了。他开车沿着盘山公路一路向西，窗外的景色从繁华的都市渐渐变成了荒凉的山野。下午三点多，他终于到达了目的地——一个名叫"清风镇"的小镇。

镇子不大，常住人口大概只有两三千人。街道两旁是低矮的平房，偶尔能看到几家小饭馆和杂货店。镇上的人看起来都很朴实，但是张伟知道，表象之下往往隐藏着不为人知的秘密。

他找了一家小旅馆住下。老板是个五十多岁的中年男人，姓王，脸上总是挂着笑容，看起来很和气。

"小伙子，第一次来我们这儿吧？"王老板一边给他登记一边问。

"嗯，来看看朋友。"张伟随口答道。

"朋友？"王老板抬起头，上下打量了他一眼，"我们这儿外地人不多，你朋友叫什么名字啊？说不定我认识。"

"叫...叫李建国。"张伟临时编了个名字。

"李建国？"王老板想了想，摇摇头，"没听过这个名字。我们镇上姓李的倒是不少，但叫建国的...好像没有。"

"可能是我记错了。"张伟笑了笑，"他说他住这儿，可能是在镇上的哪个村子里吧。"

"有可能。"王老板也没再追问，把房间钥匙递给他，"二楼最里面那间，206。卫生条件一般，你凑合着住。有什么需要就叫我。"

"好的，谢谢王老板。"张伟接过钥匙，拎着行李上了楼。

房间不大，但还算干净。一张床，一张桌子，一把椅子，仅此而已。窗户对着后面的小巷，光线不太好。张伟把行李放下，走到窗前，拉开窗帘往外看了看。

小巷里很安静，一个人都没有。对面是一堵灰色的砖墙，墙上爬满了青苔。墙角堆着几个破纸箱，旁边还有一辆旧自行车。

张伟收回目光，从口袋里掏出手机，翻出了一个号码。他犹豫了一下，还是拨了出去。

电话响了很久才接通，那边传来一个低沉的男声："喂？"

"是我。"张伟说。

"..."那边沉默了几秒，"你怎么会打这个电话？"

"我需要你的帮助。"张伟直截了当地说，"我在清风镇。"

"你疯了？"那边的声音明显提高了，"你知道那是什么地方吗？你一个人去的？"

"我一个人。"张伟说，"但我需要有人帮我查点东西。"

"查什么？"

"陈浩然。"张伟说出这个名字的时候，感觉自己的心跳都漏了一拍，"我需要知道他现在的情况。"

电话那头又沉默了。过了好一会儿，那个声音才再次响起："你确定要查他？你知道这意味着什么吗？"

"我知道。"张伟深吸了一口气，"但是我必须查。三年前的事，我不能就这么算了。"

"好吧。"对方叹了口气，"我帮你查。但是你给我听好了，在我联系你之前，你哪儿都别去，什么人都别信。这个镇子...不简单。"

"我知道了。"张伟说。

"还有，"对方补充道，"小心那个旅馆的老板。"

"王老板？"张伟愣了一下。

"对。"对方的声音变得更加低沉，"他...没你想的那么简单。"

说完，电话就挂了。

张伟握着手机，站在窗前，久久没有动。

窗外，夕阳的余辉洒在小镇上，给一切都镀上了一层金色。但是张伟知道，在这片金色之下，隐藏着的，可能是无边的黑暗。

他转过身，走到桌子前坐下，从包里掏出一个笔记本，开始写今天的观察记录。作为一个调查记者，这是他多年的习惯。

"九月七日，晴。清风镇。常住人口约三千人，以农业和少量旅游业为主。镇上的人看起来很淳朴，但对外地人有一定的戒心。旅馆老板王建国（？），五十岁左右，体型微胖，面带笑容，但眼神深处有一丝不易察觉的精明。需要进一步观察。"

写到这里，他停下笔，想起了李晓雅。不知道她现在在干什么，是不是也在想他。

他掏出手机，翻出李晓雅的照片。照片里的她笑得很灿烂，阳光洒在她的脸上，显得格外温暖。张伟看着照片，嘴角不自觉地扬了起来。

就在这时，门外传来了敲门声。

"咚咚咚。"

张伟迅速收起手机，站起来走到门口："谁？"

"是我，王老板。"门外传来王老板的声音，"给你送点热水。"

张伟犹豫了一下，还是打开了门。

王老板端着一个热水壶站在门口，脸上还是那副和气的笑容："我们这儿条件简陋，没有热水供应。你要是需要喝水或者洗漱，就用这个壶烧。"

"谢谢王老板。"张伟接过水壶。

"不客气。"王老板笑了笑，目光在房间里扫了一圈，"对了，你那个朋友...李建国是吧？你要是找不到他，可以去镇东头的老李酒家问问。那家店的老板姓李，在镇上住了几十年了，认识的人多。"

"好的，谢谢王老板。"张伟点点头。

"那你休息吧。"王老板说完，转身走了。

张伟关上门，靠在门上，眉头皱了起来。

王老板...为什么要主动告诉他老李酒家的事？他是真的热心，还是...别有用心？

张伟摇了摇头，把这些想法暂时压下去。他走到桌子前，把水壶放下，然后从包里掏出一个小型望远镜，走到窗边，开始观察对面的街道。

天色渐渐暗了下来，街道上的行人越来越少。路灯一盏接一盏地亮了起来，昏黄的灯光把街道照得朦朦胧胧的。

就在这时，张伟看到了一个熟悉的身影。

那个人穿着一件黑色的风衣，戴着一顶鸭舌帽，低着头，快步从街上走过。虽然看不清脸，但是那个身影...张伟总觉得在哪里见过。

他是谁？他为什么会出现在这里？

张伟的心跳加速了。他有一种预感，这趟清风镇之行，恐怕不会那么简单。

## 测试指引

### 一、文本精校模块测试

**开启设置**：精校设置 → 开启显示阶段精校 / 开启预处理阶段精校

**测试点**：
1. **错别字检测** — 文中包含以下错别字，看精校能否标出：
   - "灯火澜珊" → 应为"灯火阑珊"
   - "模了摸她的头" → 应为"摸了摸她的头"
   - "余辉" → 应为"余晖"
   - "朦朦胧胧" → 正确，但可观察是否误报

2. **标点符号** — 观察中英文标点混用、省略号等处理是否正常
3. **日志输出** — 打开模块日志，看精校模块是否输出了修改数量和类型统计

**预期结果**：打开一本书，切换到阅读页，精校模块应自动处理文本，日志中显示处理了多少处错误。

### 二、TTS 增强模块测试

**开启设置**：TTS 增强设置 → 开启需要的功能（自定义音色 / 自定义断句 / 自定义 TTS 引擎）

**测试点**：
1. **音色列表拉取** — 设置中是否有"拉取音色列表"按钮，点击后能否列出系统 TTS 引擎的所有音色
2. **音色过滤** — 拉取的音色列表是否排除了不需要的外语音色（如英文、西班牙文等）
3. **自定义音色** — 选择一个音色后，阅读页朗读时是否使用了选中的音色
4. **自定义断句** — 朗读时的停顿是否按设置中的规则调整
5. **日志输出** — 模块日志中是否显示 TTS 相关的调用记录

**测试步骤**：
1. 打开 TTS 增强模块设置，开启"自定义音色"功能
2. 拉取音色列表，选择一个中文音色
3. 回到阅读页，点击朗读按钮
4. 听朗读效果，观察是否使用了选中的音色
5. 查看模块日志，确认 TTS hook 是否被调用

### 三、智能文本模块测试

**开启设置**：智能文本设置 → AI 模式选择（full / light / off）

**测试点**：
1. **角色识别** — 文中出现了张伟、李晓雅、陈浩然、王老板等角色，看是否能正确识别并归类
2. **对话分段** — 对话段落是否被正确识别和标注
3. **知识库加载** — 全局知识库和本书知识库是否正常加载（首次可能为空，属正常现象）
4. **日志输出** — 模块日志中是否显示角色数量、知识库状态等信息

**预期结果**：
- AI 模式为 full 时，应注册相关 hook 并处理文本
- AI 模式为 off 时，不注册 hook，不处理文本（日志显示"钩子: 无"）
- 角色列表中应出现张伟、李晓雅等主要人物

### 四、模块配置隔离测试

**测试目的**：验证三个模块的配置互不干扰

**测试步骤**：
1. 打开文本精校模块设置，修改某个选项（如"开启显示阶段精校"）
2. 打开 TTS 增强模块设置，查看其选项是否保持原样
3. 打开智能文本设置，查看 AI 模式是否保持原样
4. 完全关闭 app，重新打开，检查三个模块的设置是否都正确持久化

**预期结果**：修改一个模块的设置不影响其他模块，重启后设置仍然正确。

### 五、模块日志测试

**测试点**：
1. 每个模块的详情弹窗中都有"日志"tab
2. 日志内容按时间倒序显示（最新的在最上面）
3. 复制按钮可以复制当前模块的所有日志
4. 刷新按钮可以重新加载最新日志
5. 日志只显示当前模块的内容，不混杂其他模块的日志
