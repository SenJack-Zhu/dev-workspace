**NativeTavern v0.1.12 (iOS Build 30)**
**Changes since v0.1.9 (Build 23)**

**Live2D & character models**
• Added Live2D import, preview, character binding, tap/drag interactions, semantic actions, and TTS lip-sync.
• Added Spine 4.1 `.skel + .atlas + texture` import and animation playback.
• Improved mobile renderer lifecycle and performance, iOS Retina clarity, preview quality, random tap motions, idle recovery, and crash resistance.

**Memory, knowledge & roleplay**
• Added long-term memory with contextual retrieval, a memory inbox, and extraction controls.
• Added local Data Bank document import/search, semantic reranking, chat citations, and context injection.
• Added RPG scenario packages, deterministic state/rules, an editor, and in-chat game controls.

**Tools, voice & settings**
• Added MCP server management, provider tool calling, and secured built-in tool execution.
• Improved speech-to-text and TTS playback, including Live2D synchronization.
• Added storage management, backup/restore improvements, capability diagnostics, and broader Chinese localization.
• Renamed OpenAI-facing labels to OAI Compatible.

**Fixes**
• Fixed chat navigation crashes, RPG editor freezes, database migrations, hidden-renderer resource usage, Live2D import/preview issues, and tap animations stopping at the final frame.
