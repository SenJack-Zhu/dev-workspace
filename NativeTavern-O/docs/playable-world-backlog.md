## 玩法里有什么

```
底栏：聊天 | 角色 | 玩法 | AI | 设置

玩法（只是菜单）
  ├─ 动态   → 新
  ├─ 故事   → 新
  ├─ 世界书 → 现有页，从底栏搬过来
  └─ 资料   → 现有库，从设置搬过来
```

世界书、资料是独立库，不是「这场绑了什么」。

## 一期

### A. 玩法菜单（#64）

- [ ] 底栏「世界书」改成「玩法」
- [ ] 点进去只有四行：动态、故事、世界书、资料

### B. 故事（#65）

一场聊天的回看。

- [ ] 大约 20 轮自动出一章（标题 + 两三句）
- [ ] 点章节回到当时那条消息
- [ ] 首页只有时间线；收件箱放二级
- [ ] 有把握的事实静默写下，不弹窗
- [ ] 没把握的进现有收件箱
- [ ] 没模型也能手动写、建章、搜索
- [ ] 关掉后提示词不再塞记忆
- [ ] 书签分叉后两支分开记
- [ ] 空态：「聊一段时间才会有故事。」去聊天，不去设置

## 二期

### C. 动态（#67）

聊天是私下，动态是公开。

- [ ] 时间线。三个键：评论、开聊、拆穿
- [ ] 公开说法可以和故事不一致；能看实情
- [ ] 有动机才发；禁止天气心情灌水
- [ ] 开聊带着这条回到那场聊天
- [ ] 拆穿后角色不能否认故事里已有的事实
- [ ] 和故事同一条世界线；分叉后分开
- [ ] 没新事就空着；无红点、无推送
- [ ] 应做：已读不回、角色互评（只评自己知道的）、用户发帖、等待帖
- [ ] 不做：关注、热搜、点赞升级、连签、真社交

依赖：故事能出章节。
