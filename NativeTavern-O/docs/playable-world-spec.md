# NativeTavern 可玩世界 · 设计与需求（审阅稿）

日期：2026-08-23  
性质：单机，不商业化。默认能聊，想玩再进玩法。  
Issue：#64 玩法菜单　#65 故事　#67 动态　（#66 已封口）

本文取代此前分散表述。以前叫过「信息披露壳」「酒馆墙」「朋友圈」「酒馆之夜」的，一律作废。

---

## 1. 产品一句话

聊天还是聊天。玩法里四个独立系统：动态、故事、世界书、资料。  
动态和故事围着一场对话长；世界书和资料是全局库。  
场景/第一夜不作为玩法一级，也不做官方小游戏。

---

## 2. 总导航

底栏五格：

```
聊天 | 角色 | 玩法 | AI | 设置
```

第三格现在是「世界书」，改成「玩法」。世界书改从玩法进去。

### 2.1 玩法页只是菜单

点底栏「玩法」，只看到五行名字。没有时间线、没有数值、没有开关。再点一行，才进那个系统。

```
玩法
  ├─ 动态     → 动态系统
  ├─ 故事     → 故事系统
  ├─ 世界书   → 世界书系统（现有页搬过来）
  └─ 资料     → 资料系统（现有资料库从设置搬过来）
```

| 编号 | 需求 |
| --- | --- |
| NAV-1 | 底栏第三项文案和图标改为「玩法」 |
| NAV-2 | 玩法页只有上述四行，再点一次才进系统 |
| NAV-3 | 菜单页不展示帖、章节、状态条、设置表单 |
| NAV-4 | 聊天顶栏不堆这四项。有章节后，顶栏可留「故事」捷径（可选） |
| NAV-5 | 设置不再当这四项的首页 |

### 2.2 不上玩法菜单的

| 留在哪 | 什么 |
| --- | --- |
| 底栏 / 首页 | 聊天、角色、群聊入口、人设 |
| 设置 | 提示词、预设、正则、变量、采样器、MCP、语音、生图、立绘、主题 |
| 聊天里 | 书签、输入、swipe |
| 砍掉 | 立绘嘴型 / 语音对口型 |

## 3. 四个系统

### 3.1 动态（新，#67，二期）

**是什么**  
第二舞台。聊天是私下，动态是公开。角色会演、瞒、互撕。你可以评、开聊、拆穿，也可以不理。

**不是什么**  
不是微信，不是信息流灌水，不催登录。

**默认**  
玩法里点进去才有。无红点、无推送、不后台刷帖。没新事就空着。

**界面**

- 时间线，倒序。一张帖：谁、一句话、可选图。
- 三个键：评论、开聊、拆穿。
- 「更多」里才有：谁能看见、写不写进世界。
- 「开聊」回到那场聊天，并带上这条帖。

**功能**

| 编号 | 级别 | 需求 |
| --- | --- | --- |
| DY-1 | 必做 | 默认不出现在聊天主路径 |
| DY-2 | 必做 | 公开说法可以和故事里的事实不一致；能看实情 |
| DY-3 | 必做 | 有动机才发（显摆/试探/隐瞒/点名）。禁止天气心情填空 |
| DY-4 | 必做 | 从这条开聊，角色知道你在问哪一条 |
| DY-5 | 必做 | 拆穿：角色必须接住矛盾，不能否认故事里已有的事实 |
| DY-6 | 必做 | 和故事、场景同一条世界线；书签分叉后分开 |
| DY-7 | 应做 | 已读不回可被提起，不弹窗 |
| DY-8 | 应做 | 角色互评，只评自己知道的 |
| DY-9 | 应做 | 用户可发帖；可选可见范围、是否写入世界 |
| DY-10 | 应做 | 等待帖：点名问你，评 / 开聊 / 不理 都算数 |
| DY-11 | 不做 | 关注、热搜、点赞升级、连签、真社交、红点 |

**空态**  
「还没有动态。去聊一场，或等故事里先记下事。」不要生成假帖。

### 3.2 故事（新，#65，一期）

**是什么**  
一场聊天的回看：自动分章，能点回当时那条消息。长线关系留下能读的东西。

**不是什么**  
不是记忆参数页，不是收件箱当首页。

**默认**  
用户照常聊。大约 20 轮出一章。不点「故事」也不影响聊。

**界面**

- 首页：章节时间线（标题 + 两三句 + 时间）。
- 点章节：回到那场聊天并滚到原消息。
- 「记一笔」在故事页上，或长按消息。
- 记忆收件箱、以后的故事树，放故事里的二级，不回玩法菜单。

**功能**

| 编号 | 级别 | 需求 |
| --- | --- | --- |
| ST-1 | 必做 | 约 20 轮自动一章，可提前记一笔 |
| ST-2 | 必做 | 章节可跳回原消息 |
| ST-3 | 必做 | 首页只有时间线 |
| ST-4 | 必做 | 有把握的事实静默写入，不弹窗 |
| ST-5 | 必做 | 没把握的进现有收件箱 |
| ST-6 | 必做 | 没配模型也能手动写、手动建章、能搜 |
| ST-7 | 必做 | 关掉后提示词不再塞记忆 |
| ST-8 | 必做 | 书签分叉后两支分开记 |
| ST-9 | 后做 | 故事树、两支对照、导出、日更入口 |

**空态**  
「聊一段时间才会有故事。」按钮去聊天，不去设置。

### 3.3 场景 / RPG：已封口

现有工程里有一套 RPG 引擎（属性、背包、任务、规则裁定）。它的正当用途是：有人导入/制作规则包时，让这场对话的数字是真的。

它**不是**：

- 给所有人准备的官方小游戏
- 和动态、故事并列的日常入口
- 「第一夜」这种我们编的住店解谜

**结论**

- 玩法菜单不放「场景」
- 不做「第一夜」门面包
- 引擎和编辑器留在深处（现有设置/编辑器即可），给已经会玩规则包的人
- #66 不再当一期必做
- 产品 UI 已封口（`kRpgProductUiEnabled = false`）：设置入口和聊天手柄隐藏；引擎与导入代码保留

聊天里现有的 RPG 大面板也不要为了推销这层再改一版新手状态条。没开规则包，聊天里不要出现这套 UI。

### 3.4 世界书（已有，搬入口）

**是什么**  
独立的设定库。一条条写：人名、地点、规矩。聊到关键词，自动塞相关条目。  
就是现在底栏那个世界书，整页搬到玩法 → 世界书。

**不是什么**  
不是「这场勾选了哪几本」。书是全局的。某本书可以指定给某个角色，那是书上的选项。

**界面**  
保持现有世界书页：书列表、条目、导入新建。不要改成场次过滤器。

**功能**

| 编号 | 级别 | 需求 |
| --- | --- | --- |
| WI-1 | 必做 | 从底栏改为玩法 → 世界书进入，能力不减 |
| WI-2 | 必做 | 首页仍是书库，不是某场聊天的附件列表 |
| WI-3 | 已有 | 全局 / 所有角色 / 指定角色，仍在书的设置里 |

---

### 3.5 资料（已有，搬入口）

**是什么**  
独立的文档库。丢小说、笔记、PDF，按问题去搜一段塞进对话。  
和世界书的差别：世界书是你写的短条目；资料是整份长文件。

**不是什么**  
不是「这场绑了哪些文件」的清单。库是全局的。挂到角色或某次聊天，是文件上的选项。

**界面**  
现有资料库从设置挪到玩法 → 资料。首页是文库，不是绑定向导。

**功能**

| 编号 | 级别 | 需求 |
| --- | --- | --- |
| DB-1 | 必做 | 玩法 → 资料进入独立文库 |
| DB-2 | 已有 | 导入、检索；没 Embedding 也能用本地搜 |
| DB-3 | 已有 | 删除后文件和索引不留 |
| DB-4 | 后做 | 角色只能看到某几章（战役圣经加深时再做） |

## 4. 现有界面要改什么

### 聊天页

- 顶栏现在偏挤（RPG 手柄、书签、更多）。RPG 手柄不要常驻；没开场景时不要出现。
- 开了第一夜：输入框上方一条状态，不要继续用现在那整块 6 Tab 面板占聊天。
- 不在顶栏放动态、世界书、资料。

### 设置

- 记忆收件箱、资料库、场景编辑器不再当玩法首页。
- 资料库改从玩法进。
- 场景编辑器改从场景系统进。
- 收件箱改从故事系统进。
- 界面详细程度（简洁 / 标准 / 全部）留在设置。ST 那堆设置不搬家。

### 底栏

- 世界书 → 玩法。不要加第 6 格。

## 6. 分期

**一期（先做）**

1. #64 底栏玩法 + 四行菜单（动态、故事、世界书、资料）
2. #65 故事章节

**二期**

3. #67 动态

**不进一期/二期门面**

- #66 第一夜 / 把场景做成玩法一级

**不做**

- 抽卡、体力、红点催登、真社交
- 酒吧皮、朋友圈皮
- 嘴型对口型
- 把玩法页做成仪表盘或设置页
